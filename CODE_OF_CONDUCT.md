# Code of Conduct

Short version: don't be hostile, don't abuse this project, don't misattribute
the work.

This repository contains a proof-of-concept for a security vulnerability. It
is published strictly for research, disclosure, and defensive purposes.

## Expectations

- Use the code and writeup as-is, for understanding and verification.
- Credit the source when you reference or extend the findings.
- Report harm, misuse, or inaccuracies through the project's normal
  communication channel.

## Not covered by this document

This document does not waive any law, license, or policy. Running the PoC
against a system you do not own or are not authorized to test is your
responsibility, not the project's.
